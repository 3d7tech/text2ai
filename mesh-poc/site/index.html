Offgrid Mesh

Chat phone-to-phone with no internet and no mobile network. Messages hop between phones over Bluetooth and Wi-Fi Aware.

Download for Android (APK)

Test build · commit __COMMIT__ · __DATE__ · Android 8.0+

This page can't send messages itself. Browsers can't use Wi-Fi Aware or act as a Bluetooth device, so the messaging only works in the installed app. iPhone isn't supported yet.

Install

  1. Tap Download, then open the file.
  2. If asked, allow your browser to install unknown apps.
  3. Open Offgrid Mesh PoC and allow the Nearby devices / Bluetooth permissions.
  4. Make sure Bluetooth and Wi-Fi are switched on. Wi-Fi doesn't need to connect to a network.

Test with 2–3 phones

  1. Turn off mobile data, and disconnect from any Wi-Fi network (leave Wi-Fi switched on).
  2. Set a name: /nick Amaka
  3. Send a message. The top bar shows neighbors per radio (ble, aware).
  4. Hop test: put A and C out of range of each other, with B in the middle. A's message reaches C through B ("2 hops").
  5. Carry test: A sends while only B is near. Walk B over to C, and C receives it.
  6. Private message: /peers, then /dm Amaka hello

iPhones, Chromebooks and tablets

  1. On an Android tablet or phone with the app, tap Hub and switch it on. Keep it plugged in.
  2. On each device, join the same Wi-Fi (no internet needed) and scan the QR code shown on the hub.
  3. iPhone: in Safari, Share → Add to Home Screen. Chromebook: Chrome ⋮ → Cast, save and share → Create shortcut → Open as window.
  4. Chat, and send photos and videos. Everything stays on your home network.

Pass it on, no internet needed

In the app, tap Share app:

  • Bluetooth, Quick Share, Xender, SHAREit, WhatsApp: sends the app file.
  • Bluetooth as .zip: use this if Bluetooth refuses the file. Open the zip in Files, then tap the app inside.
  • Wi-Fi + QR code: the other phone doesn't need anything installed. They scan the first code to join your phone's Wi-Fi, then the second to download.

Known limits

  • Not encrypted yet. Don't send anything sensitive.
  • Photos and videos work through the household hub. Over the phone-to-phone mesh it's text only for now.
  • Wi-Fi Aware needs a supported phone (many Pixel and Samsung models). Bluetooth works on all phones.
